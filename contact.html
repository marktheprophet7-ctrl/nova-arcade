Contact & Feedback

Have feedback about a game, found a bug, or want to suggest a new arcade machine? You can contact the NOVA ARCADE project through its public GitHub issue tracker.

Report a problem or suggest a feature

Open a new NOVA ARCADE issue on GitHub

Tell us which game you're playing, what happened, and what you'd like to see improved. A GitHub account may be required to submit an issue.

Privacy matters

GitHub issues are public. Please do not post private account details, phone numbers, email addresses, passwords, or other sensitive information there. If you are submitting a privacy-related request, keep the public description general.
